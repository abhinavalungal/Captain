# Shuddha now — brand kit

The official Shuddha now logo: a compass whose needle is a kayak. The hull is a
single vesica — two circular arcs — so it reads as a compass needle, a kayak
seen from above (the cockpit and seat sit just aft of centre) and a leaf. The
compass ring opens where the hull passes through it.

Full guidelines: **`Shuddha-now-brand-guide.pdf`** (symbol, logo system, clear
space, minimum sizes, colour, typography, usage).

## Which file to use

| Need | File |
|---|---|
| Website / app header on a light background | `svg/shuddha-now-logo.svg` |
| Header or slide on Deep Pine or any dark colour | `svg/shuddha-now-logo-reverse.svg` |
| On photography or Jade | `svg/shuddha-now-logo-white.svg` |
| One-colour print, stamps, embroidery | `svg/shuddha-now-logo-mono.svg` |
| Square spaces, title slides, documents | `svg/shuddha-now-logo-stacked*.svg` |
| Letterheads, cover pages, marketing | `svg/shuddha-now-logo-tagline*.svg` |
| Social avatars, stickers, watermark | `svg/shuddha-now-mark*.svg` |
| Anything under 32 px | `svg/shuddha-now-mark-compact.svg` or `svg/favicon.svg` |
| App icon | `svg/shuddha-now-app-icon.svg`, `png/shuddha-now-app-icon-{192,512,1024}.png` |
| Word, PowerPoint, email signatures | the matching file in `png/` (transparent, 1200 or 2400 px wide) |
| Link previews (Open Graph) | `png/shuddha-now-social-1200x630.png` |
| Browser tab | `png/favicon.ico` (16/32/48) and `svg/favicon.svg` |

The SVGs are the masters. Their lettering is converted to outlines, so they
never depend on a font being installed — never retype the wordmark.

## Typography

**Manrope** — free under the SIL Open Font License, from
[Google Fonts](https://fonts.google.com/specimen/Manrope). The wordmark is
Manrope Bold (SHUDDHA) and Medium (NOW), uppercase, tracking +160. Use Bold for
headlines and Regular / Medium for body text.

## Rules

Keep a clear space of one cap height (the height of the letters in SHUDDHA) on
every side. Don't stretch, recolour, rotate the needle, add shadows or effects,
or put the full-colour logo on a dark background — use the reverse version.
