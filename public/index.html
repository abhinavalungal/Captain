Add K.R.1.S to perform.geoserves.com

Paste this before </body> on the page. The widget works out its own API address from where the script was loaded, so nothing else on your page needs configuring — it works the same regardless of what this is hosted on.

Then, on wherever this is deployed (its environment variables):

  1. Set KRIS_ALLOW_ORIGIN to https://perform.geoserves.com so the browser is allowed to call K.R.1.S from your domain.
  2. Replace verifyToken() in src/httpHandler.js with your real session check, and remove KRIS_DEV_SESSION. The department dropdown on this page only works because prototype sign-in is on; on your page, getToken should return the user's real session token.
  3. On vessel pages, call KRIS.setContext({ vesselId, vesselName }) when the page loads.
Prototype sign-in trusts whatever department the browser claims. It exists so this page can be demonstrated before real authentication is wired. It must be off on any site real users can reach.
